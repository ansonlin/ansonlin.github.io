Kubernetes應用程式佈署工具-Kubeapps

Posted on 2020-02-15 Edited on 2020-03-13

Kubeapps是一个基于web的UI，用于在Kubernetes集群中部署和管理应用程序。

預先安裝Helm

Helm

安裝Kubeapps

透過Helm (v3) chart來安裝最新版的kubeapps，並指定namespace為kubeapps

完成後存取的訊息

more info:
GetStart Readme 參數值

建立Kubernetes API token

存取kubeapps UI面板需要透過API token，以下建立並查詢

取得token值

存取kubeapps面板

如果沒有設置ingress，則需要透過port forward來轉發，此處設置為8888

開啟站台並輸入步驟2產生的token，完成示圖

畫面說明：
Applications表示目前透過Helm佈署的應用程式、
Catalog表示在Bitnami Helm Hub上可供佈署的應用程式
Service Instance還在阿法階段就不說啦XD

測試佈署Wordpress

1.點選 Catalog >> 搜尋下 wordpress >> 進入後點選右方綠色按鈕 “Deploy”

2.輸入相關參數值，完成後點選最底下Submit

3.等待容器建立後開啟站台

移除kubeapps

To uninstall/delete the kubeapps deployment:
