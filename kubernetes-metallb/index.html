Kubernetes地端裸機負載均衡器MetalLB

Posted on 2019-12-08 Edited on 2020-02-15

LoadBalancer

LoadBalancer 是提供給公有雲使用的類型，如果一個 Service 設定為這個類型時，就會利用叢集中的 Cloud Provider 元件去呼叫公有雲的服務 API 來建立負載平衡器，接著跟這個 Pod 進行綁定。
但在地端部署時，該類型會實現類似 NodePort 機制，也可以額外設定 externalIPs 來直接存取指定的 Port。

接下来的MetalLB，提供给私有 Kubernetes 用户带来了一个方便、可用的软體解决方案。

MetalLB

MetalLB支援兩種模式： Layer2、BGP ，更多可參考 Metallb。

多服務共用一個LB IP
