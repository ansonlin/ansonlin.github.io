使用Nexus自建docker、npm及maven私有及快取倉庫

Posted on 2020-03-27

目的：本文透過Nexus自建npm及maven私有及快取倉庫，存儲並加快下載速度。

1.快取倉庫:快取常用的倉庫,加快構建速度，此處以docker、npm、maven作為範例。
2.私有倉庫:並上傳打包好的專案,上傳至私有倉庫，此處以docker、npm、maven作為範例。。

安裝前必備
1.CentOS 7
2.docker
3.docker-compose
4.Nexus OSS 3.21

Nexus安裝設置

此處透過docker-compose來啟動Nexus，套用以下YAML

$ docker-compose -f nexus/docker-compose-traefik.yaml

然後開啟站台測試下 http://nexus.你的Nexus IP.nip.io

Docker Repository

Docker Repository設置

Docker Repository分為三種模式：
1.Docker(Host)
2.Docker(Proxy)
3.Docker(group)

Docker(Host)

存放本地端image使用，操作簡略如下：
Repository > Repositories > Create repository > docker (hosted)

Name:取一個喜歡的名稱
Repository Connectors
此處不設置對外port(http/https)，在後續的group模式，統一對外即可、允許匿名下載(Allow anonymous docker pull)
Docker Registry API support
允許使用v1 API存取倉庫

Docker(Proxy)

用來加快爾後下載速度，操作簡略如下：
Repository > Repositories > Create repository –> docker (proxy)

Docker(group)

將host或proxy模式集合起來，統一對外使用，操作簡略如下：
Repository –> Repositories –> Create repository –> docker (group)

Name:取一個喜歡的名稱
Repository Connectors
設置對外port(5000)、允許匿名下載(Allow anonymous docker pull)
Docker Registry API support
允許使用v1 API存取倉庫

然後把前面加入的兩個repository勾選進group即可。

最後別忘了要把docker realm勾選才會套用喔！！

NPM Repository

NPM Repository設置

NPM(Host)

存放本地端image使用，操作簡略如下：
Repository > Repositories > Create repository > npm (hosted)

NPM(Proxy)

用來加快爾後下載速度，操作簡略如下：
Repository > Repositories > Create repository –> npm (proxy)

分別設置官網以及淘寶

NPM(Group)

將proxy模式集合起來，統一對外使用，操作簡略如下：
Repository –> Repositories –> Create repository –> npm (group)

Maven Repository

Maven Repository設置

Maven(Host)

存放本地端image使用，操作簡略如下：
Repository > Repositories > Create repository > maven (hosted)

Maven(Proxy)

用來加快爾後下載速度，操作簡略如下：
Repository > Repositories > Create repository –> maven (proxy)

分別設置官網以及阿里雲

Maven(Group)

將proxy模式集合起來，統一對外使用，操作簡略如下：
Repository –> Repositories –> Create repository –> maven (group)

Maven Proxy測試

先新增設定檔
$ vi .m2/settings.xml

執行verify確認套件可正常從指定的maven proxy中下載
$ mvn -s .m2/settings.xml –batch-mode verify

正常執行就會顯示Success訊息
