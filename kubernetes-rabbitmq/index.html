發表於 2020-02-12

RabbitMQ介紹說明

RabbitMQ is an open source message broker software that implements the Advanced Message Queuing Protocol (AMQP).

RabbitMQ文檔說明

高併發下RabbitMQ限流實踐

業務場景

舉一些我們平常生活中的消費場景，例如：火車票、機票等，通常來說這些服務在下單之後，後續的出票結果都是異步通知的，如果服務本身只支持每秒1000訪問量，由於外部服務的原因突然訪問量增加到每秒2000並發，這個時候服務接收者因為流量的劇增，超過了自己系統本身所能處理的最大峰值，如果沒有對消息做限流措施，系統在這段時間內就會造成不可用，在生產環境這是一個很严重的問題，實際應用場景不止於這些，本文通過RabbitMQ來講解如何對消費端做限流措施。

消費端限流機制

RabbitMQ提供了服務質量保證( QOS)功能，對channel（通道）預先設置一定的消息數目，每次發送的消息條數都是基於預先設置的數目，如果消費端一旦有未確認的消息，這時服務端將不會再發送新的消費消息，直到消費端將消息進行完全確認，注意：此時消費端不能設置自動簽收，否則會無效。

在之後，放寬了限制，除了對channel設置之外，還可以對每個消費者進行設置。

佈署成功的畫面

使用下列方式存取

Credentials:
    Username      : digiwin
    echo "Password      : $(kubectl get secret --namespace default rabbitmq-1581661485 -o jsonpath="{.data.rabbitmq-password}" | base64 --decode)"
    echo "ErLang Cookie : $(kubectl get secret --namespace default rabbitmq-1581661485 -o jsonpath="{.data.rabbitmq-erlang-cookie}" | base64 --decode)"

To Access the RabbitMQ AMQP port:
    kubectl port-forward --namespace default svc/rabbitmq-1581661485 5672:5672
    echo "URL : amqp://10.40.46.101:5672/"    
( kubectl port-forward --namespace default svc/rabbitmq-1581661485 --address 0.0.0.0 5672:5672 )

To Access the RabbitMQ Management interface:
    kubectl port-forward --namespace default svc/rabbitmq-1581661485 15672:15672
    echo "URL : http://127.0.0.1:15672/"

常用的參數

參數 描述 Default
global.storageClass Global storage class for dynamic provisioning nil
rabbitmq.username RabbitMQ application username user
rabbitmq.password RabbitMQ application password random 10 character long alphanumeric string
rabbitmq.erlangCookie Erlang cookie random 32 character long alphanumeric string
rabbitmq.plugins List of plugins to enable rabbitmq_management rabbitmq_peer_discovery_k8s
rabbitmq.clustering.k8s_domain Customize internal k8s cluster domain cluster.local
persistence.storageClass Storage class of backing PVC nil
persistence.existingClaim RabbitMQ data Persistent Volume existing claim name, evaluated as a template “”
persistence.path Mount path of the data volume /opt/bitnami/rabbitmq/var/lib/rabbitmq
ingress.enabled Enable ingress resource for Management console false
ingress.hostName Hostname to your RabbitMQ installation nil

More info: [rabbitMQ] https://github.com/helm/charts/tree/master/stable/rabbitmq
