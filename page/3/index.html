Posted on 2019-11-29 Edited on 2020-02-15

此篇介紹透過kubeadm來建立單一control plane角色的Kubernetes，關於HA集群請參考 Kubernetes HA

安裝前必備

  1. Hardware
    至少有2 GB或以上的記憶體(依應用而定)、2顆 CPU、節點之間網路連接正常

  2. OS
    Redhat / CentOS 7.6、Minimum install

  3. Container Runtime
    為擺脫單一 Container Runtime的依賴，後續多家推出各式各樣的 open source container runtime，但Docker還是普羅大眾最上手好用的，以下也以docker為例

  4. 防火牆設置

以下描述不同角色，需要開放的Inbound Ports

  1. Control-plane node(s) ports
    TCP 6443 ==> Kubernetes API Server
    TCP 2379-2380 ==> etcd server client API
    TCP 10250-10252 ==> Self

  1. Worker node(s) ports
    TCP 10250 ==> Kubernetes API
    TCP 30000-32767 ==> NodePort Service

指令如下

或直接停用防火牆(不推薦)

  1. 停用分頁Swap

Check br_netfilter module

  1. 其它檢查

kubelet ==> 在所有節點上執行,用來控制啟動pod及容器
kubectl ==> 用來控制整個集群
